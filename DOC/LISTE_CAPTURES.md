# Captures du guide du joueur (16)

Mode d'emploi : lancer le programme avec `DEFAULTLICENSELESS=1` dans INI.TXT (pas d'image officielle),
faire la capture avec Win+Maj+S, enregistrer en PNG dans `DOC\IMAGES\` sous le nom indique.
Remettre l'INI.TXT comme avant ensuite.
